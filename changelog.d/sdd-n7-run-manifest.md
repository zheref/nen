- `nen run start|append|verify|budget` keep a batch run's manifest (contract `nen.run/v0.1`, Hatsu ruling HR-5) at `<git-common-dir>/hatsu/runs/<run-id>.json`: `start` records the launch-time idle answers (the same answers again is the resume, other answers exit 1); `append` records every PR the run opens whatever its base, idempotent on the same facts, `updated` on a moved head or base, exit 1 on another issue, kind or effort; `verify --target` reads every recorded PR live and reports open, merged and closed-unmerged with the unmerged list, exit 1 when any PR could not be read; `budget` sums the run's efforts' usage ledgers against `--max-minutes`/`--max-tokens` (or `idle.budget`), and `--claim` refuses at exit 1 once either is reached. `start` and `append` take `--dry-run`.
- `nen loop slots --from-run <run-id> --target <owner/name>` builds the efforts document from the manifest and live reads -- PR state, `nen pr ready` in process, a stop marker in the PR's worktree -- so no field is caller-typed; anything unread keeps its slot held and is named.
- `nen wc overlap --efforts <a,b,...> --repo <path> [--base <ref>] [--always-overlaps <paths>]` computes file disjointness from each effort's merge-base diff: `disjoint` (exit 0), `overlap(<paths>)` or `unknown` (exit 1).
- `nen stage check --exclusive --target <owner/name> --issue <N>` exits 1 when an issue carries two stage-family labels, the family read from `nen/labels.json`; a taxonomy with no stage family or an unread issue is exit 1, never exclusive.
- `nen parse futon` reads an optional `--idle` flag of the scope (HR-5), reported as `idle` in both outputs.
- `nen parse izanami` classifies the new verbs: `run start` and `run append` mutating (read-only under `--dry-run`); `run verify`, `run budget`, `wc overlap`, `stage check` and `loop slots --from-run` read-only.
- Behaviour changes: `nen parse futon --json` gains an `idle` key (`false` unless `--idle` was typed), `--idle` after `then` -- previously prose -- is now refused at exit 2 with the line moved, and an unquoted label selector whose last word is ` --idle` (or a scope whose first word is `--idle `) now reads as the flag rather than as part of the label; quote such a label to keep it. `nen run --help` documents five subcommands where it documented one, and `nen run rerun-failed` now refuses the manifest verbs' flags at exit 2. `nen wc` and `nen stage` gain one subcommand each and refuse the new flags on their other subcommands. `nen loop slots`'s usage line names `--from-run`; a call with neither `--efforts` nor `--from-run` says so at exit 2 as before.
