- `nen/contract.json` reads an optional `precedenceRestatedIn` list (zheref/nen#474, Hatsu HR-1): the repository-relative files that restate `precedence` in prose, as a run of code spans joined by `**>**`. `nen schema check` refuses by pointer a list with no `precedence`, an empty list, a repeated file and a path leaving the root, and adds the row `nen/contract.json#precedenceRestatedIn` **only when the key is declared**. The row FAILS, required, naming the file and line, on a restatement that drifted from the array, a declared file that restates nothing, and a file it could not read. With Hatsu's committed `docs/WORKFLOW.md` declared, the row reads `1 restatement file agrees with precedence`.
- The shape of `precedence` itself (unique, non-empty strings, refused by pointer) shipped in v0.26.0 (zheref/nen#478).
