- **direct** — `nen direct matrix --registry <path> --taxonomy <path> --repo <path> [--job <c,d>] [--domain <e,f>] [--json]` enumerates every (job, domain, language) answer `nen direct resolve` gives, so a consumer can render the whole routing table without re-implementing the resolver. Each cell is what `resolve` answers for an issue carrying that one job and that one language (or none, the `*` column) in that domain, computed by `resolve`'s own functions — the route, phase fallback and stand-ins, the aggregate, both sides resolved (surface, spelled alias, restart line, interactive tools, snapshot quote, live lookup) and the effort; nothing is re-derived. Which domains a job can be in is `resolve`'s domain derivation asked about bounded witness issues (the job alone or with up to two other jobs; a kind no rule names, then each named kind; no role, then each named role; no label, then one per pattern). The first witness per domain is printed and passes to `resolve` as typed. A domain no witness derives is `unreachable`, and a cell a reviewer wins with no stand-in is `skipped`. `--json` is `nen.direct.matrix/v0.1`, grouped job → domain → language. Invalid or unroutable input refuses by `resolve`'s own names at exit 1, an unknown or empty filter at exit 2 (refs #426).
