- `nen surface mirror generate` writes an Antigravity persona's `tools:` list in Antigravity's own tool names (zheref/nen#505), as the block list its subagents page documents (`tools` · `string[]`), instead of carrying the Claude Code names as one comma-joined line. The map sits on the antigravity row of `src/surface/rules.ts`, each entry citing its pages, and takes only the names both Antigravity pages give (the maintainer's ruling of 2026-10-22, OQ-1): `Read` → `view_file`, `Bash` → `run_command`. Every other name, and a scoped grant such as `Bash(git:*)`, is dropped and named in a report `note:` (`antigravity: <name>: dropped … from tools (…); wrote …`), never written, because the page warns an unmapped name "may cause the subagent process to hang". A persona whose list names no mapped tool, or a list the parse cannot read as tool names, is refused at exit 2. No `tools` key, or an empty one, passes through unchanged.
- `nen surface capabilities` reports Antigravity's read-only control as `honoured (the persona's tools list, mapped to this surface's names: Read -> view_file, Bash -> run_command; …)`, derived from the map, so it reads `unverified` again if the map is emptied.
- Behaviour changes: every Antigravity persona file with a `tools` key changes, writers included. Their `Edit`, `Write` and `MultiEdit` are unmapped too, so a writer mirrored for Antigravity is limited to `view_file` and `run_command` until the pages converge. A consumer's committed Antigravity mirror reads stale under `surface mirror check` until it is regenerated (an older build's bytes are recognised, as for #270 and #328; any other edit still reads hand-edited), and `generate`'s `notes` gain one antigravity line per persona that named an unmapped tool.
- The `tools:` list parse no longer splits at a comma inside a scoped grant's parentheses, so `Bash(git log, git diff)` is one item. A list naming one now reads read-only when it names no write tool, where it used to fail closed as unreadable; on cursor such a persona gains `readonly: true`.
