- New `nen scorecard` family ([#669](https://github.com/zheref/nen/issues/669)). `trend` scores each repository's merged pull requests per ISO week on the improvement aspects a caller's section catalogue declares. `--catalogue` is read at run time and its `aspects` array is the list and the order, so no aspect is compiled into nen. Each cell carries improves, unchanged, regresses, unrecorded and net; `--markdown` prints a review page. `snapshot` writes one repository's completed week to `<out>/<YYYY-Www>.json` with no generation time, so a scheduled workflow can commit it idempotently (the same pull requests and catalogue file give the same bytes). Both read GitHub through `gh pr list --state merged` only. A repository that cannot be read is `could-not-read` with the reason, never an empty row.
