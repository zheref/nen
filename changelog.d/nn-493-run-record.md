- `nen run record read|write --schema <id> --id <run-id> [--from <file>] [--dry-run]` (zheref/nen#493, AC-11): a caller's resumable run record, validated against a schema shipped as data (`hatsu.spec.run/v0.1`, Hatsu's `dowsing-chain` record) and kept at `${XDG_STATE_HOME:-$HOME/.local/state}/hatsu/specs/<run-id>.json`. The run id is matched whole against the schema's pattern before any path is built; the record's `schema`, `caller` and `runId` are checked before its fields; a write is the whole document at `0600` in a `0700` directory, through a temp file and a rename. Verdicts `valid` · `written` · `would-write` · `absent` · `invalid` · `could-not-read`. It sits beside the batch manifest (`run start|append|…`), which stays under the git common dir.
