### Added
- `nen report check --repo <path> [--variant <name>] [--self-test]` renders every variant `reports.sections` declares in Markdown and HTML from the example data, and refuses a refused render, a surviving `{{`, a block sequence that is not the declared one, the two formats disagreeing, an ask with zero or more than one starred option, or escaping that shows in a Markdown cell. Exit 2 is wiring: no sections, or a missing template or example. ([#406](https://github.com/zheref/nen/issues/406))
