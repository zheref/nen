- `nen parse` gains list slots (`<slot>{+}`, `<slot>{&}`, every item of an enumerated list checked) and alternations (`<a:..>{+}|<b:..>[+]|<c>`, the free alternative taken only when no piece of the value is an enumerated value), and `nen backlog fetch` and `nen report data` gain a repeatable `--label` (AND over an effort's issue and PR labels) and a `--severity <name>[+]` band; an undeclared label, or a piece of one containing `&`, is refused at exit 2 before any read. An unfiltered document and a plain slot are unchanged, but a `--grammar` template that used `|` or `{…}` outside `<…>` as literal text changes meaning: `|` there is now an alternation (refused when it cannot resolve), and `{…}` declares a list joiner on the slot before it.
