- **changelog** — `collate` recognises existing `##` or `### vX.Y.Z — YYYY-MM-DD` sections without an Unreleased anchor. `--date YYYY-MM-DD` supplies a deterministic calendar date, and human/JSON previews name the actual heading. Preamble, release history, fragment text and existing delivery PR citations are preserved; unsupported shapes refuse before writes or fragment deletion. The legacy empty `### Unreleased` / `--theme` route remains supported (refs [#446](https://github.com/zheref/nen/issues/446)).
