The private-name guard honours a repository's COMMITTED NAMED LIST beside the caller's ignore file, in one call and with no new flag: `nen/workflow.json` → `privateNames.namedFile` (the eighteenth block; a repo-relative path, no default; a gate change under `schema set`) names a file of private repositories whose NAME a recorded ruling made public while their code stays private (zheref/hatsu's `scripts/private_name_named.txt`, the ruling of 2026-10-19). The checkout's declaration is only the switch. Every guarded verb — `issue file|comment|edit-body|consolidate-close`, `idea file`, `pr open|edit-body|threads reply|settle`, `wake fire|verify` through the shared adapter, and `release-publish` by the same rule through its own runner — reads the ref, the policy copy, the path and the list at the remote's default branch (`refs/remotes/origin/HEAD`), never from the checkout, so the change under review cannot write its own exemption, retarget `branch.base` at itself or point the guard at a file of its own (#363's F8 holds; Feitan's and Nobunaga's finding on this change); a line counts once merged there and fetched. The read happens after the target's visibility, so a private target spends no `git show`. One exact `owner/name` per line; a bare `name` is a usage error (exit 2) naming the line and never the entry, and a same-named private repository under another owner is still a hit. Whatever cannot be read on that route — the ref unset, no policy or no such file there, a directory or symlink, a policy this build cannot parse — names nothing and the run says so with the verb's prefix; nothing is read under `--skip-private-name-check`. The every-name-exempted refusal counts both lists, and `--allow-all-ignored` is now accepted with a declared named list and no ignore file (with neither it still exits 2). An ignored hit says which list exempted it: `(named list)` or `(ignore file)` on stderr, and `privateNameCheck.hits[].ignoredBy` (`"named-list"` | `"ignore-file"` | `null`) under `--json`, beside the unchanged `ignored` boolean; an entry both lists exempt reports the named list. A consumer that joined the two lists into a temporary file before every write can pass its ignore file alone once it declares the key. (Closes #441)
