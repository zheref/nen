- `nen spec diff --from <inventory> --to <inventory>` (zheref/nen#493, AC-5): the added, removed and changed rows between two inventories of one member, by stable row id, each changed field with its `from` and `to`. A different `sha` alone is not a change, so identical inputs — or inputs differing only in their commit — give an empty diff. Two different `origin`s exit 2; an input that is not a readable `nen.spec.inventory/v0.1` document (or recorded `could-not-read`) is verdict `could-not-read`, exit 1. The verb reads no checkout and refuses `--repo`.
