- `nen scaffold init` now writes a CI workflow for a repository with more than one lane — two stacks such as a Next.js + Expo monorepo, or one stack in several directories: `.github/workflows/nen-shu.yml` from the new `templates/ci-lanes.json`, one `shu-<lane>` job per lane on that lane's own stack runner, every verb run with `--lane`. When a lane's stack has no CI template (or its name is not a plain token) no workflow is written and a `no CI workflow:` note names each such lane and the manual step, instead of skipping the workflow with only a re-run hint (zheref/nen#586).
