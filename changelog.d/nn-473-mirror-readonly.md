A persona whose only routable keys would be the derived one is still refused. **Codex:** nothing is written, because a custom agent file cannot override the parent sandbox (`sandbox_mode` "don't override the parent configuration"); each read-only persona is a report `note:` (`codex: <name> is read-only at source; Codex documents no per-agent read-only control …`), with or without `--models`. **Antigravity** and **claude-code** output is unchanged.
