- `nen schema set` gains two structural edits (zheref/nen#587): a pointer ending in `/-` appends `--value` as the last item of an existing array, in the array's own style, and `--json`'s new `at` field names the index it took; and an existing object or array is replaced whole by an object or array from `--value`, in the layout it had and the file's own indentation. Both are validated by the file's loader before the write and read back after it. Changing a value's kind stays refused, and a replaced structure's removed keys are matched against the gate scopes and the canon pin as an added value's are. A structure replace never deletes a `$` note: one over an object or array that carries one is refused, and so is a `--value` carrying one.
