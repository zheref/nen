- The private-name guard matches a private repository named after an ORDINARY WORD only in repository-shaped forms, never as a bare word (zheref/nen#535, the maintainer's ruling of 2026-10-25). The forms are `owner/name` (with a markup or quote run after the slash, e.g. `owner/_name_` or `owner/[name]`), `owner/name#N`, a URL path, the list's own owner with spaces around the slash or across a line break, `name#N` and `name.git`. Look-alike slashes (U+2215, U+2044, U+29F8, U+2571) read as `/`. The decision is an exact, case-insensitive match of the whole name against a word list embedded in the binary, so it reads no host dictionary and answers the same everywhere. The list is `src/issue/ordinary-words.json`: 10,737 words from SCOWL 2020.12.07 under Kevin Atkinson's permissive licence, with SCOWL's Copyright file vendored as `src/issue/ordinary-words.COPYRIGHT`. It is generated by `bun src/dev/ordinary-words.ts --tarball <path>`, which checks the tarball's sha256, and its test pins the count and the words' sha256. A hyphenated, dotted or otherwise multi-word name is never ordinary and keeps the bare-word match. Every guarded verb shares the rule: `issue file|comment|edit-body|consolidate-close`, `idea file`, `pr open|edit-body|threads reply|settle|ledger post`, `wake fire|verify` and the release publisher. The publisher's v0.28.0 notes had been refused at exit 4 through one of nen's own dotted schema ids; a flag such as `--name` was never a match, because `-` is a word character.
- Behaviour changes: a bare use of a policed ordinary-word name is no longer a hit. It is reported on a stderr line, `<verb>: not matched: <field>:<line>: private repository #<k> (ordinary word: matched only as owner/name, name#N or a URL)`, and listed under `ruled` in `--json`'s `privateNameCheck`, which is `[]` when nothing was checked. A name the ignore file or the named list exempts reports as an ignored hit, as before. Every hit gains `form` (`bare` | `repository-shaped`) and `class` (`ordinary-word` | `null`), so a caller comparing a hit or the verdict by exact equality must add them. The ignore file, the committed named list, `--skip-private-name-check` and every exit code are unchanged. `nen/workflow.json`'s security review scope now claims `src/issue/privacy*`, `src/issue/ordinary-words*` and `src/dev/release-publish*`.
