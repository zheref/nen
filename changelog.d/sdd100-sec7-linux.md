- `nen canon lint --rules <path>`: the SEC-7 refusal names the symlink by a root-relative path in both branches, so the message no longer depends on the host. A path lexically inside the root is counted from the root as given; any other spelling (the root's realpath, a symlinked root, a link into it) is counted from the real root, so through a directory symlink inside the root the two can name the same file differently. Before, a path lexically inside the root was named as given (absolute when given absolute), which made the realpath spelling read differently on Linux, where `/tmp` is its own realpath, and on macOS (zheref/nen#527, from #528).
