- `nen canon lint --rules <path>`: the SEC-7 refusal names the symlink by its root-relative path however the caller spelled `--rules` (relative, the root's absolute path, its realpath, a symlinked root, a link into it), so the message is the same on every host. Before, a path lexically inside the root was named as given, which made the realpath spelling read differently on Linux, where `/tmp` is its own realpath, and on macOS (zheref/nen#527, from #528).
