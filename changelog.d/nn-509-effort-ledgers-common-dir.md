- One effort-id grammar for every ledger keyed by an effort (zheref/nen#509, #511 folded in): `nen phase`, `nen usage`, `nen session`, `nen direct resolve --record` and `direct answer`, `nen stop answer --record`, `nen run append|budget --effort`, `nen shu <verb> --effort` and the new `nen report data --effort`. The grammar is `src/ledger/effort.ts`'s `EFFORT_ID`, the one declaration in `src/`: letters, digits, `.`, `_`, `-`, `/`, `#` and `:`, starting with a letter or digit, no `.`/`..` segment, no leading `<letter>:`. An id it refuses is exit 2 with one text from every verb, `effort id '<id>' is refused: <why>.`
- The phase, usage, session and direct ledgers move to the git common directory, `<git-common-dir>/.nen/{phases,usage,sessions,direct}/` (`src/ledger/roots.json`), so a resumed effort keeps its history after its worktree is removed. Outside git they stay under `<--repo>/.nen/<family>/`. `nen report data` reads the common directory and the reported checkout's older directory beside it, and `--effort <id>` (repeatable) scopes `phases[]`, `usage[]` and `sessions[]`.
- Behaviour changes: these verbs now spawn `git rev-parse --git-common-dir`, and all but `report data` also spawn `git worktree list`: `phase begin|end|show`, `usage record|show`, `session record|show`, `direct resolve --record`, `direct answer`, `run budget`, `shu <verb> --effort` (or `NEN_EFFORT`), and `report data` (rev-parse only). Each turns a git refusal other than "not a git repository" (an unsafe `safe.directory`, a broken repository) into exit 2. `stop answer` already asked git. A ledger file that is a symlink or not a regular file is refused, as is a ledger path that resolves outside the git common dir: exit 1 for phase, usage and session, and exit 2 for the direct record, each family's documented code. A refused `phase begin|end` moves nothing. `report data` skips an effort whose ledger is in both homes, with a warning. `phase` and `usage` now admit `#` and `:` ids they refused. `direct` and `stop answer` now refuse ids they admitted (a space, a leading `.`, a `-` start, a character outside the alphabet), and their refusal text changes. A ledger an older build left at `<checkout>/.nen/<family>/` is read in place by a reader, with its path on stderr, and moved into the common directory by the next write. A copy in both homes is exit 1 naming both. This fallback is read through the 0.28 line and removed in 0.29.0. `nen report data` without `--effort` now reads every effort of the repository, not only the checkout's.
